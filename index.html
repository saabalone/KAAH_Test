Aide de KAAH

Jouer un coup
  • Noir joue en bas et commence. Touchez une de vos billes, puis une case verte : c'est le coup. Toujours deux touchers. Pour un groupe de 2 ou 3 billes, touchez la première bille du groupe.
  • Les pendules (cadres gris à droite du plateau) démarrent quand on en touche une. Touchez-la encore pour mettre en pause : le plateau se cache.
  • Abandonner (drapeau) et Nulle (signe =) : deux petits boutons de chaque côté du compteur d'éjections de chaque joueur. Toucher l'un demande une confirmation verte (Valider ou Refuser) ; seul le joueur qui a la main peut abandonner, mais chacun peut proposer nulle. La confirmation nomme le joueur qui demande. Le cadre orange Tour n indique à qui c'est de jouer.
  • Touchez le cadre d'un joueur pour changer son nom.
  • Le texte bleu au-dessus du nom de la partie est la position actuelle en notation compressée : touchez-le pour la copier.
  • Partie terminée : touchez le cadre orange Gagné Options (ou Nulle Options) pour choisir Revanche (couleurs inversées), Same (même setup) ou Change (autre variante). En face-à-face, chacun reste assis à sa place : le plateau se retourne (les Noirs sont alors du côté de celui qui les joue) mais les pendules, compteurs et noms restent du même côté.
  • On gagne avec 6 billes éjectées (le compteur de chaque camp est près de sa piste).
  • Tout ce qui attend une réponse de votre part est en vert (choix d'une branche, confirmations, nulle, Annuler).
Les boutons de la colonne de gauche
  • ☰ (en haut) : affiche le nom de chaque bouton.
  • Nouvelle partie : la partie en cours reste dans Mes parties.
  • Mes parties : les parties enregistrées automatiquement. Un premier toucher montre un aperçu, le second charge la partie. Un badge sur l'icône (vert, puis rouge) indique le nombre de parties enregistrées quand il devient important — pensez à en supprimer.
  • Variantes et Puzzles : positions de départ et puzzles de KAAWA (aperçu au premier toucher, chargement au second). Une rangée de boutons les classe (Équilibrées, Handi, types ; Easy, Medium...), le choix est retenu.
  • Conseils (ampoule) : les coups les plus joués dans la base de KAAWA pour la position affichée.
  • Menaces (cible) : affiche les poussées possibles des deux camps (vert : camp au trait, orange : l'autre, rouge : éjection).
  • Séquence : l'arbre des coups ; toucher un coup y ramène le plateau. Commentaires : un commentaire par coup. Occurrences : les autres endroits de la partie où la même position apparaît. Au-dessus de ces trois onglets, |<H / <H / H> retiennent les ENDROITS visités en touchant l'arbre (comme le retour d'un navigateur web) — différents des flèches de coup précédent/suivant, ci-dessous.
  • Face-à-face : mode deux joueurs de chaque côté d'un téléphone posé à plat (voir plus bas).
  • Sons : un interrupteur par son, plus un curseur de volume.
  • Exporter / Importer : enregistre ou charge une partie dans un fichier, au format de KAAWA.
Revenir en arrière, Annuler, branches
  • |<< début, << coup précédent, >> coup suivant, >>| dernier coup. On peut naviguer sans rien perdre.
  • Jouer un autre coup depuis une position passée crée une branche : les anciens coups restent dans la Séquence.
  • Annuler (vert) supprime le dernier coup, après confirmation. Il est grisé quand il n'y a rien à annuler.
Mode Face-à-face
  • Posez le téléphone à plat entre les deux joueurs. Le plateau ne bouge jamais ; les noms, les coordonnées et les fenêtres se lisent de chaque côté (à gauche du plateau de bas en haut, à droite de haut en bas).
  • Le bouton est un interrupteur. Sur Android l'écran se met en paysage tout seul ; sur iPhone, tournez le téléphone à la main (et désactivez le verrouillage de rotation).
  • Menu ☰ déplié : les libellés se retournent vers Blanc quand c'est à Blanc de jouer.
Enregistrement des parties
  • Chaque coup est enregistré automatiquement dans le navigateur de cet appareil (pas de compte, pas d'internet).
  • Si vous videz les données du navigateur, les parties disparaissent : utilisez Exporter pour garder une partie importante.
Installer ou ouvrir KAAH
  • Avec internet (recommandé) : ouvrez https://saabalone.github.io/KAAH_Test/, puis installez KAAH (Chrome / Edge : menu du navigateur, « Installer » ; iPhone, dans Safari : Partager, « Sur l'écran d'accueil »). Il marche ensuite hors ligne.
  • PC : extrayez le dossier reçu, puis double-clic sur index.html (il s'ouvre dans votre navigateur).
  • Android : extrayez le dossier avec l'application Fichiers, puis tapez dans la barre d'adresse du navigateur file:///storage/emulated/0/Download/KAAH/index.html (à adapter si le dossier est ailleurs).
  • iPhone : pas de méthode simple sans adresse internet (voir le mode d'emploi iPhone dans le dossier docs).
  • Ouvert depuis un fichier, KAAH se joue très bien mais ne s'installe pas comme une application ; la version s'affiche « inconnue » : c'est normal.
  • Les modes d'emploi complets (PC, Android, iPhone) sont dans le dossier docs.
Problèmes connus
  • Android : la page a pu se figer (plus aucune réaction). Le bouton Retour du téléphone puis un retour sur la page la débloque. Une cause probable (la question « nulle » en boîte du navigateur) a été supprimée : dites-moi si cela se reproduit.
  • iPhone : pas de verrouillage automatique en paysage ; le premier son ne sort qu'après un premier toucher.
  • Face-à-face en paysage : le zoom à deux doigts ne fonctionne pas (il fonctionne dans les autres modes).
  • Les sons « Occ » se déclenchent peut-être trop souvent : à revoir.
  • Cette aide est volontairement courte.
Signaler un problème
  • Indiquez : le modèle de l'appareil et sa version (Android 14, iOS 17...), le navigateur utilisé, la version de KAAH (en haut de cette fenêtre), ce que vous avez fait, ce qui s'est passé, et une capture d'écran si possible.
  • Si cela concerne une partie : Exporter la partie et envoyez le fichier.
Ce qui n'est pas encore dans KAAH
  • Pas encore là : réglages (couleurs, tailles, mode simple sans relief), modes de pendules (Chrono/Bonus/Délai), créer une partie depuis une suite de coups Nacre / AbaPro (et les positions « My »), mode correspondance (code KAA1), corbeille et import de fichiers .json / .csv, bloc-notes NP et aide complète, fenêtre Permutations, solveur de puzzles, adversaire artificiel (jouer seul contre la machine).
  • Petits points connus : pas de zoom à deux doigts en face-à-face paysage ; pas de son à la fin d'un puzzle ; le son d'Occ est peut-être trop fréquent.
  • La liste complète est dans la page « Ce qui n'est pas encore dans KAAH » (dossier docs). Il vous manque autre chose ? Dites-le dans votre rapport : une fonction de KAAWA que vous utilisez et qui n'est ni dans le jeu ni dans cette liste.
