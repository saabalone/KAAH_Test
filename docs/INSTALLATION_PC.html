KAAH sur PC (Windows, Mac, Linux)

Mode d'emploi pour les testeurs. Vous avez reçu un fichier KAAH.zip : c'est tout ce qu'il faut. Aucune connexion internet n'est nécessaire.

Ouvrir KAAH (2 minutes)

  1. Enregistrez KAAH.zip sur votre ordinateur (Bureau ou Documents).
  2. Extrayez-le (ne l'ouvrez pas directement depuis le zip) :
    • Windows : clic droit sur le fichier → Extraire tout… → Extraire.
    • Mac : double-clic sur le fichier.
  3. Ouvrez le dossier extrait, puis faites un double-clic sur index.html. Il s'ouvre dans votre navigateur.
    • S'il s'ouvre dans un éditeur de texte : clic droit → Ouvrir avec → Chrome, Edge, Firefox ou Safari.
  4. Le plateau d'Abalone apparaît, avec les billes noires en bas.
  5. Pour le retrouver facilement : clic droit sur index.html → Envoyer vers → Bureau (créer un raccourci).
Bon à savoir. Vos parties sont enregistrées dans le navigateur utilisé. Si vous ouvrez KAAH avec un autre navigateur, vous ne verrez pas les mêmes parties. Dans ce mode, KAAH ne s'installe pas : c'est normal, il se joue très bien. La fenêtre d'aide (bouton i?) indiquera « Version : inconnue » : c'est normal aussi.

Ce qu'il faut vérifier

Pour chaque ligne : ✔ ça marche, ✘ ça ne marche pas (dites pourquoi).

  1. Le plateau s'affiche, les billes sont bien placées.
  2. Vous jouez 3 coups (touchez une bille, puis une case verte).
  3. Vous fermez le navigateur puis rouvrez index.html : la partie est reprise là où vous l'avez laissée.
  4. Changez la taille de la fenêtre (agrandissez, réduisez, étirez en hauteur puis en largeur) : le plateau reste un hexagone régulier et les billes restent bien dans leurs cases.
  5. Touchez une pendule : les deux passent de vert à noir/blanc avec deux traits verts ; touchez-la encore : elles redeviennent vertes (pause).
  6. Le bouton Sons ouvre la liste ; un coup fait un bruit (son de l'ordinateur allumé).
  7. Le bouton Exporter télécharge un fichier de partie (.json).
  8. Le bouton i? ouvre l'aide ; vous pouvez la fermer avec Fermer (en haut ou en bas) ou la touche Échap.

Si ça ne marche pas

  • Page blanche ou plateau absent : rechargez la page (touche F5). Sinon, notez le message d'erreur.
  • Les sons ne sortent pas : vérifiez le volume, puis cliquez d'abord une fois dans la page.

Plus tard : installer KAAH comme une application (avec une adresse https)

Ce mode ne sera possible que lorsque KAAH sera publié à une adresse internet en https (adresse prévue : https://saabalone.github.io/KAAH_Test/). Il permet une vraie installation et un fonctionnement hors ligne.

  1. Ouvrez Chrome ou Edge et tapez l'adresse. Attendez que le plateau s'affiche complètement (la première fois, KAAH se copie sur l'ordinateur).
  2. Dans la barre d'adresse, à droite, cliquez sur l'icône d'installation (un petit écran avec une flèche vers le bas), puis Installer.
    • Edge : menu ⋯ → Applications → Installer ce site en tant qu'application.
    • Chrome, si l'icône n'apparaît pas : menu ⋮ → Diffuser, enregistrer et partager → Installer la page en tant qu'application.
  3. Une fenêtre KAAH s'ouvre, sans barre d'adresse. Une icône est ajoutée au bureau ou au menu Démarrer.
  4. Test hors ligne : fermez KAAH, coupez la connexion (Wi-Fi ou câble), relancez KAAH depuis son icône : il doit s'ouvrir et se jouer.

Firefox (ordinateur) ne sait pas installer. Safari (Mac) : menu Fichier → Ajouter au Dock.

Mettre à jour : ouvrez KAAH avec internet, fermez-le complètement, rouvrez-le (une ou deux fois). Le numéro de version est en haut de la fenêtre Aide.
