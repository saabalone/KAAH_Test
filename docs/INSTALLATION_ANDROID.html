KAAH sur Android

Mode d'emploi pour les testeurs. Deux méthodes : A (avec l'adresse internet, recommandée) ou B (avec le fichier KAAH.zip reçu, sans internet).

Important. Ouvrir un fichier local dans un navigateur est moins bien pris en charge sur Android que sur ordinateur : selon le téléphone et le navigateur, ça marche ou pas. C'est justement ce que nous testons. Si ça ne marche pas, notez précisément ce qui se passe et dans quel navigateur.

Méthode A — avec l'adresse internet (recommandée)

Adresse de KAAH : https://saabalone.github.io/KAAH_Test/
Il faut internet une seule fois, le temps de l'installation ; ensuite KAAH marche hors ligne comme une vraie application.

  1. Ouvrez Chrome et tapez l'adresse. Attendez que le plateau s'affiche complètement (la première fois, KAAH se copie sur le téléphone).
  2. Touchez le menu ⋮ (en haut à droite), puis Installer l'application (ou, selon la version : Ajouter à l'écran d'accueil, puis Installer).
  3. Confirmez avec Installer. L'icône KAAH apparaît sur l'écran d'accueil.
  4. Lancez KAAH depuis son icône (et non depuis Chrome) : il s'ouvre en plein écran, sans barre d'adresse.
  5. Test hors ligne : fermez KAAH, activez le mode avion, relancez KAAH depuis son icône : il doit s'ouvrir et se jouer.

Autres navigateurs : Samsung Internet : menu ☰ → Ajouter la page à → Écran d'accueil. Opera : menu → Écran d'accueil. Firefox : menu ⋮ → Installer.

Mettre à jour : ouvrez KAAH avec internet, fermez-le complètement (retirez-le des applications récentes), rouvrez-le, une ou deux fois. Le numéro de version est en haut de la fenêtre Aide.

Méthode B — sans internet, avec le fichier KAAH.zip

  1. Enregistrez KAAH.zip dans le dossier Téléchargements du téléphone (depuis un message, un mail, ou par câble USB).
  2. Ouvrez l'application Fichiers, allez dans Téléchargements, touchez KAAH.zip puis Extraire. Un dossier KAAH apparaît. Ne le déplacez pas.
  3. Ouvrez un navigateur (Chrome, ou Opera, ou Firefox) et, dans la barre d'adresse, tapez : 
    file:///storage/emulated/0/Download/KAAH/index.html
    Si votre dossier n'est pas dans Téléchargements, adaptez le chemin. Pour le connaître : dans Fichiers, appui long sur index.html → Détails (ou Infos) → chemin.
  4. Le plateau d'Abalone apparaît, avec les billes noires en bas.
  5. Pour le retrouver : ajoutez la page aux favoris du navigateur.

Si le navigateur refuse (message « accès refusé », « fichier introuvable » ou page vide) : essayez un autre navigateur (Opera a fonctionné lors de nos essais), et notez le message exact.

N'ouvrez pas index.html en le touchant directement dans l'application Fichiers : cela ne marche en général pas (avertissement content://).

Bon à savoir. Vos parties sont enregistrées dans le navigateur utilisé. Changer de navigateur, c'est changer de parties. La fenêtre d'aide (bouton i?) affiche la version même avec la méthode B.

Ce qu'il faut vérifier

Pour chaque ligne : ✔ ça marche, ✘ ça ne marche pas (dites pourquoi). Faites la méthode A, et si possible aussi la B.

  1. Méthode A : « Installer l'application » est proposé ; l'icône KAAH apparaît ; lancé depuis l'icône, KAAH s'ouvre sans barre d'adresse et en mode avion ; la version s'affiche dans l'aide (par exemple « KAAH_Test_ph21_v1 »).
  2. Le plateau s'affiche, les billes sont bien placées. Dans quel navigateur ?
  3. Vous jouez 3 coups (touchez une bille, puis une case verte). Les cases et les boutons sont assez grands pour votre doigt.
  4. Vous quittez le navigateur puis rouvrez la page : la partie est reprise.
  5. Touchez une pendule : les deux passent de vert à noir/blanc avec deux traits verts ; touchez-la encore : elles redeviennent vertes (pause).
  6. Le bouton Sons ouvre la liste ; un coup fait un bruit (volume des médias allumé).
  7. Le bouton Face-à-face : essayez à deux, téléphone à plat, écran en paysage. Tout est lisible de chaque côté ?
  8. En portrait, puis en paysage, le zoom à deux doigts fonctionne. (Attendu : il ne fonctionne pas en face-à-face paysage.)
  9. Le bouton i? ouvre l'aide ; vous pouvez la fermer avec Fermer, en haut ou en bas.
  10. Le téléphone est-il lent ? (jouer un coup, ouvrir la Séquence : réponse immédiate ou avec un temps d'attente ?)

Si ça ne marche pas

  • La page ne réagit plus (ce problème a été vu une fois) : appuyez sur la commande Retour du téléphone, puis revenez sur la page KAAH. Notez ce que vous faisiez juste avant.
  • Les sons ne sortent pas : touchez d'abord l'écran une fois, puis vérifiez le volume « médias ».
