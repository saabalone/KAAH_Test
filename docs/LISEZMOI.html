Documentation de KAAH

Pour les testeurs

Choisissez le mode d'emploi de votre appareil :

  • PC — Windows, Mac, Linux
  • Android
  • iPhone / iPad

Chaque mode d'emploi propose deux méthodes — A : l'adresse internet (recommandée), B : le fichier KAAH.zip, sans internet — et contient : les étapes, une liste de vérifications à cocher, quoi faire si ça ne marche pas, et un modèle de rapport à me renvoyer. Une fois KAAH ouvert, le bouton i? affiche une aide courte.

Ce qui n'est pas encore dans KAAH : les fonctions de KAAWA qui restent à faire. Dites-moi si vous en voyez d'autres qui manquent.
